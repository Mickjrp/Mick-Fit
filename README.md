# Mick Fit (PWA) · v2.0

แอปซ้อม + อาหารรวมเป็นแอปเดียว สำหรับ iPhone ใช้ offline ได้ ข้อมูลเก็บในเครื่องเท่านั้น
ไม่มีขั้นตอน build: ไฟล์ในโฟลเดอร์นี้คือแอปที่ใช้งานจริง

## แท็บ

| แท็บ | ปุ่มด้านบน | มาจาก |
|---|---|---|
| วันนี้ | ซ้อม · อาหาร | `train/#workout` · `meal/#today` |
| แผน | ตารางซ้อม · แผนอาหาร | `train/#week` · `meal/#plan` |
| เมนู | – | `meal/#menu` |
| คลัง | – | `meal/#stock` |
| ฉัน | น้ำหนัก · ตั้งค่าซ้อม · ตั้งค่าอาหาร · ข้อมูล | `train/#body` · `train/#settings` · `meal/#config` · หน้า Backup ของ shell |

## แผนที่โค้ด

```
index.html  shell.css  shell.js   Shell: แถบแท็บ, ปุ่มสลับด้านบน, หน้า ข้อมูล (Backup/Restore), ย้ายน้ำหนักตัวครั้งแรก
sw.js                             Offline cache ของทั้งแอป (ตัวเดียว)
manifest.webmanifest  icons/      ติดตั้งบน Home Screen
train/                            แอปซ้อมเดิม (โครงไฟล์เหมือนเดิม: js/data.js, js/storage.js, js/views/*.js ...)
meal/                             แอป meal prep เดิม (index.html ไฟล์เดียว + cookbook.json, img/, page/)
```

Shell โหลดสองแอปไว้ใน `<iframe>` แล้วสลับหน้าด้วย `#hash` โค้ดของแต่ละแอปจึงแยกกันเหมือนเดิม
ชื่อตัวแปร, CSS และ id ไม่ชนกัน ทั้งสองแอปอยู่ origin เดียวกันจึงใช้ `localStorage` ร่วมกัน

## ส่วนที่เชื่อมกัน

- **น้ำหนักตัว** มีชุดเดียวที่ `gtl.bw.v1` บันทึกได้จาก ฉัน › น้ำหนัก หรือการ์ดน้ำหนักในหน้า วันนี้ › อาหาร
- **วันเทรน/วันพัก** ของเป้าแคลดูจากตารางซ้อม (`gtl.program.v1`) วันที่เป็น Rest ใช้เป้าวันพัก ปุ่มวันเทรน/วันพักบนหน้าอาหารยังกดเปลี่ยนรายวันได้
- **ธีม** ตั้งที่เดียว: ฉัน › ตั้งค่าอาหาร › ธีม
- **Backup** ปุ่มเดียวที่ ฉัน › ข้อมูล (Export CSV ของการซ้อมยังอยู่ใน ตั้งค่าซ้อม)

## ย้ายข้อมูลจากแอปเดิม

- ถ้า repo ใหม่อยู่ใน GitHub บัญชีเดียวกับแอปเดิม (`<username>.github.io/...`) แอปใหม่เห็นข้อมูลเดิมเองตอนเปิดครั้งแรก
  น้ำหนักตัวจากแอปอาหารจะถูกคัดลอกมาเฉพาะวันที่แอปซ้อมยังไม่มี (ถ้ามีทั้งสองแอปในวันเดียวกัน ใช้ค่าของแอปซ้อม)
- ถ้าไม่ใช่บัญชีเดียวกัน: ไป ฉัน › ข้อมูล › Restore จากไฟล์ เลือกไฟล์ backup ของแอปซ้อมเดิม แล้วทำซ้ำกับไฟล์ Export JSON ของแอปอาหารเดิม
- แอปเดิมกับแอปใหม่บนบัญชีเดียวกันใช้ข้อมูลชุดเดียวกัน ช่วงทดลองอย่าจดในสองแอปพร้อมกัน

## ทดสอบบน Mac
```bash
cd mick-fit
python3 -m http.server 8000
```
เปิด http://localhost:8000 ใน Chrome → Cmd+Option+I → Cmd+Shift+M (ขนาด iPhone)
แท็บ Application → Service workers ติ๊ก **Update on reload**

## อัปโหลด (GitHub Pages)
1. อัปโหลดทั้งโฟลเดอร์ให้โครงสร้างเหมือนเดิม (รวม `train/`, `meal/img/`, `meal/page/`, `.nojekyll`)
2. Settings → Pages → Deploy from a branch → `main` / root
3. ทุกครั้งที่แก้ ให้เปลี่ยน `CACHE` ใน `sw.js` และ `VERSION` ใน `shell.js` ให้ตรงกัน แล้วเปิดแอปบน iPhone 2 ครั้ง
4. ถ้าเพิ่มไฟล์ใหม่ ให้ใส่ชื่อไฟล์ใน `ASSETS` ของ `sw.js` ด้วย

> repo แบบ public บน GitHub ฟรี ทุกคนจะเห็นรูปและสูตรจาก cookbook ใน `meal/img/` และ `meal/page/`

## ติดตั้งบน iPhone
เปิดลิงก์ใน **Safari** → Share → **Add to Home Screen** → Add แล้วเปิดจากไอคอน **Mick Fit**
